# 💛 Site Happy

O **Happy** é uma aplicação web desenvolvida para facilitar a localização e o agendamento de visitas a casas de acolhimento e orfanatos[cite: 1, 2]. O projeto busca levar felicidade para crianças facilitando a conexão entre a comunidade e essas instituições.

> 📌 **Objetivo:** Projeto desenvolvido para fins de estudo e prática do ecossistema front-end utilizando HTML5, CSS3 e Bootstrap.
