# 🤝 AJUDA+

O **AJUDA+** é uma plataforma web criada para apoiar e conectar pessoas dispostas a ajudar vítimas de tragédias e desastres naturais. A aplicação permite que voluntários façam doações, ofereçam apoio presencial ou compartilhem campanhas em destaque para ampliar o alcance e o impacto social.

Para demonstrar o uso do aplicativo, a interface foi desenvolvida simulando a experiência completa de navegação em um *smartphone*.

---

## 📱 Funcionalidades

- **Maneiras de Ajudar:**
  - ❤️ **Doar:** Encontre campanhas e faça doações diretamente.
  - 👥 **Ser Voluntário:** Candidate-se e ofereça apoio presencial.
  - 🔗 **Divulgar:** Compartilhe campanhas para engajar mais pessoas.
- **Campanhas em Destaque:** Visualização de ações ativas e verificadas.
- **Interface Mobile Responsive:** Experiência imersiva que simula o uso do app em um dispositivo móvel.
